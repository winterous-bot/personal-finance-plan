个人财务计划 V1.2 更新说明
1. 新增和编辑资产均增加必填“资产归属人”（输入已有名字时提供候选），资产列表支持按归属人筛选；注意首页总资产、计划与配置分析仍是所有归属人的合计，不表示“本人净资产”。
2. 选择现金大类时显示可选“到期日”。到期前30天、7天内、当天及逾期后，在首页待关注事项显示分阶段提示；仅打开 App 时提示，不是系统推送。
3. 旧版本资产不会删除。旧数据未填写归属人时在资产列表标识为“未填写”，编辑时需补录归属人；旧现金资产没有到期日则不会触发到期提醒。
4. V1.0/V1.1 的备份 JSON 仍可导入；V1.2 导出的备份包含新字段。更新前务必先导出备份。
5. 将升级包全部文件覆盖上传 GitHub Pages 仓库。PWA 缓存名称更新，升级后请完全关闭并重新打开应用或刷新网页。不要删除主屏幕应用或清空站点存储。

个人财务计划 V1.1 更新说明：新增、编辑资产时「细分类别」改为随资产大类切换的下拉框。已有资产及旧备份兼容；若旧资产标签已从设置中移除，编辑原资产时仍会显示该旧标签，切换大类则重置。升级请将本包文件全部覆盖上传，并在更新前先导出一次备份。

个人财务计划 V1.0｜安卓优先 PWA

一、部署到 GitHub Pages
1. 登录 GitHub，新建公开仓库，例如 personal-finance-plan。
2. 将 ZIP 解压后的 index.html、app.js、style.css、sw.js、manifest.webmanifest、icon.svg、icon-192.png、icon-512.png 上传到仓库根目录（README 可以一同上传）。
3. 打开仓库 Settings → Pages → Build and deployment，将 Source 设为 Deploy from a branch，Branch 选择 main / (root)，保存。
4. 访问 https://你的用户名.github.io/personal-finance-plan/ （如果仓库名字不同，URL 跟着改变）。
5. 用安卓手机 Chrome 打开上述网址，点击浏览器菜单 → 添加到主屏幕 / 安装应用。

二、第一步配置
1. 设置 → 修改汇率：初始 HKD、USD 汇率是演示值，录入外币资产前请更新。
2. 资产 → 新增：录入资产名称、分类、币种、当前估值和日期。
3. 计划 → 编辑：录入财富目标、年月、每月新增投入、预期收益率。
4. 计划 → 调整配置比例：设定各类目标占比之和为100%。
5. 报表 → 保存本月快照：每月更新资产估值后保存一次。
6. 设置 → 导出加密备份：保存到安全位置并牢记密码。建议每月备份。

三、主要限制
- 所有财务数据保存在当前设备浏览器 IndexedDB，不会上传到 GitHub，没有跨设备自动同步。
- 网页是静态托管，GitHub 仓库不要提交真实财务数据或备份文件。
- 首次访问需要联网，之后已缓存的应用文件可离线加载；离线不是永久可靠的备份方式。
- 产品行情和汇率不自动更新。提醒只在打开 App 时计算，不是系统通知。
- 财富目标采用固定收益率的复利情景模拟，未纳入通胀、税费及波动；不能保证实际达到。
- 总资产不是净资产；V1.0 尚无负债/资金流水，也不计算准确投资收益率。
- 本版根据原 Excel 的空白规划模板预置4大类11细类，不包含实际资产数据，不直接解析 Excel 文件。可通过加密 JSON 导出/导入在不同设备手动迁移。

四、更新与维护
以后替换网页文件即可更新程序，但请先导出备份，且不要清除站点数据。GitHub Pages 要启用 HTTPS（默认支持）。
